## The IO Redistributable.

This is a work originally derived by the `Microsoft.IO.Redist` package,
but it expands that and adds a lot and useful utilities.

Additionally it ports all these into .NET 8 .

It adds:

-> A new , lightweight and better `MemoryStream` class implementation

-> Partial support for opening, reading and writing files by using the `FileStream` class

-> Publicly-exposed console streams

-> Useful `FileInfo` and `DirectoryInfo` extension methods

-> Reworked directory enumeration classes that are contained in the `Enumeration` namespace
